# Architecture Decision Record (ADR)

## How to Write an ADR

1. Copy this template into `02-design/adr/` using the file name `NNNN-kebab-case-title.md` (e.g. `0001-sqlite-with-wal-journal.md`).
2. Define the decision clearly, with concrete examples.
3. Document all edge cases and error conditions.
4. Use pseudocode or code snippets to illustrate the expected behavior.
5. Reference any database schemas involved.
6. Number ADRs sequentially (`0001`, `0002`, ...); never reuse a number.
